OpenDuckFrame 0.4.0

  • 重新设计紧凑工作台：分组设置、对齐的控件列、独立滚动区域，以及固定的来源与开始／停止操作区。
  • 新增 ArtCNN C4F32 / C4F16 原生 2× SDR 超分，可与 ODF-VFI 补帧分别配置。
  • 新增可跳过、可从帮助菜单重看的三步新手引导。
  • A redesigned compact workbench with grouped settings, aligned controls and fixed source/action areas.
  • ArtCNN C4F32 / C4F16 native 2× SDR super resolution, independently configurable from ODF-VFI frame generation.
  • A skippable three-step guide that can be replayed from Help.

ArtCNN 输入不超过 1920×1080，原生 2× 输出不超过 3840×2160。实际画质和帧率取决于输入、设置与设备。

This community build is ad-hoc signed and supports signed in-app updates. It is not Apple notarized. macOS may ask for Screen Recording or Accessibility permission again after an upgrade. 此社区版未经过 Apple 公证，升级后可能需要重新授权。
