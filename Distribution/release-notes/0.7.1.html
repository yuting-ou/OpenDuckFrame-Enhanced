OpenDuckFrame Enhanced 0.7.1

  • Apple 低延迟的窗口／显示器模式新增“插帧画质”：自动保留运行时支持的尺寸，或选择 720p 流畅优先。只缩小插帧推理，原帧和输出尺寸不变；生成帧可能变软，也不保证达到目标帧率。
  • 实时内容判重改为逐像素精确比较，低比特、色度、Alpha 和采样点之外的变化不再被误丢弃；停止采集时会释放快照，且不会清掉新一代采集。
  • 合并上游 0.6.3 的屏幕录制权限恢复修复：权限说明留在窗口列表内，不再叠在系统提示上；被拒绝后提供“打开系统设置”。
  • 实时预览运行但尚未增强时，操作区明确显示“停止采集”。
  • 切到视频文件时会停止窗口／显示器采集并取消待提交的实时计划；文件模式即使发现残留采集，也仍可用“停止采集”收口。
  • GitHub 链接指向增强版仓库，并禁用继承来的上游更新源，避免上游版本覆盖增强功能。
  • Live Apple low-latency window/display profiles add Automatic / 720p Interpolation detail. Only intermediate inference is reduced; originals and output keep source dimensions, generated frames may soften, and target FPS is not guaranteed.
  • Repeated live content is detected by exact pixel comparison, preserving low-bit, chroma, alpha and unsampled-pixel changes. Capture stop releases the owned snapshot without clearing a newer generation.
  • Includes the upstream 0.6.3 Screen Recording recovery fix: guidance stays inline with an Open System Settings action instead of stacking an app sheet over the system prompt.
  • The action area now says Stop Capture while a live preview is running before enhancement is active.
  • Switching to a video file stops window/display capture and cancels pending live plans; file mode can still retire unexpected leftover capture with Stop Capture.
  • GitHub links target the Enhanced repository, and the inherited upstream update feed is disabled so an upstream release cannot replace enhanced features.
