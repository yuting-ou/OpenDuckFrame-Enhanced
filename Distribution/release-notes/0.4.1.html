OpenDuckFrame 0.4.1

  • 移除显示器来源的全屏预览选项，增强画面跟随来源；旧配置不会重新开启该预览。
  • 视频文件的全屏输出选项继续保留。
  • Removes the fullscreen preview option for display sources; output follows the source even when an older profile enabled that preview.
  • Keeps the fullscreen output option for video files.

This community build is ad-hoc signed and supports signed in-app updates. It is not Apple notarized. macOS may ask for Screen Recording or Accessibility permission again after an upgrade. 此社区版未经过 Apple 公证，升级后可能需要重新授权。
